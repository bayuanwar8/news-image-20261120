Sum up the world's news of Friday 20 November 2026 in one image. A Node 22 program (standard library only) draws a one-page newspaper front page — "Friday 20 November 2026" — from scratch: date masthead, stat strip, three hero stories (Zelensky as a big named figure on the Kyiv bridge strikes, Cyclone Akvan coming ashore in Odisha, the AI sell-off sinking Asia's markets), ten more pictured stories, a "WHERE IT HAPPENED" world map with numbered pins, 22 briefs, and a DATE CHECK box naming the Thursday stories left out — 35 stories, 7 regions, 16 drawings in all. Its own TTF rasterizer and PNG encoder, no network, fully deterministic: two runs write byte-identical PNGs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
